# cmpsc202-Project-Problem04
Group tasked with problem 4: Booking Rooms Problem for COMPSCI 202 Project

# Project 1 Overview

This project focuses on developing and comparing algorithms to find a way to book as little rooms as possible to save money for conference meetings. We use both a naive (benchmark) solution as well as a sorting and scanning method to improve efficiency. This project demonstrates algorithm design, analysis, and implementation.
